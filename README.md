# unofficial-horizon-mods

A collection of mods and tools for Horizon that are unofficial or still in development.

## Tools

### [Horizon Translator](https://merenotnoonereal.github.io/Horizon-Translator/)
A tool for converting Java shaderpacks and mods for use with Rust.

## Mods and ports

- **[Horizon Mods](https://github.com/Azetechofficial/Horizon-mods)** — A repository by AzetechOfficial featuring Litematica, Mod Menu, and voice chat.
- **[TrueLightFX Lite — Horizon Edition](https://github.com/OGCRAFTNET/TrueLightFX-Lite-Horizon-Edition)** — A Horizon port by OGCRAFTNET of TrueLightFX Lite, described as an “IRIS&OPTIFINE v5.6.3” shader.
- **[Horizon Mod](https://github.com/ballbobeta/horizon-mod)** — Adds combat hitboxes and multi-key bindings.

## Server tools

- **[Meridian](https://github.com/Akirabane/Meridian)** — A Rust proxy for Horizon that relays players to Horizon servers and supports routing, login modes, and console commands. Seamless server switching is still in development.
